
# Mobile Test Scenarios

## Login Flow

- Verify login with valid credentials
- Verify error message with invalid password
- Verify error message when email is empty
- Verify error message when password is empty
- Verify keyboard behavior on input fields
- Verify login button state before and after entering credentials

## Onboarding Flow

- Verify onboarding screens are displayed in the correct order
- Verify user can skip onboarding
- Verify user can complete onboarding successfully
- Verify app permissions are requested at the correct step

## App Stability

- Verify app does not crash after launch
- Verify app behavior after closing and reopening
- Verify app behavior with poor internet connection
- Verify loading states are displayed correctly
