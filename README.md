I created this portfolio to demonstrate my understanding of software testing fundamentals, mobile application testing, bug reporting, and basic automation logic.

As someone with an iOS development background, I am familiar with mobile app flows, user interface behavior, edge cases, and the importance of delivering a stable user experience.

- Basic iOS UI automation using XCTest
